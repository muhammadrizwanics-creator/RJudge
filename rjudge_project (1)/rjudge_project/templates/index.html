How to use RJudge

  1. Create an account and log in.
  2. Open Problems and pick a problem. Read the statement, formats and sample.
  3. Write your solution in VS Code and save it as .c or .py.
  4. Choose the file (or paste the code) and press Submit.
  5. Read the verdict, fix your code and submit again as often as you need.
  6. Open your Dashboard to see solved problems and past submissions.

Verdicts explained

Accepted
Every test case passed.
Wrong Answer
Your program ran but printed something different from the expected output.
Compilation Error
The code could not be compiled. Check syntax and missing semicolons.
Runtime Error
The program crashed while running.
Time Limit Exceeded
It took too long, often because of an infinite loop.

Guide for beginners

Hidden test cases

The sample on the page is only one example. Your teacher also keeps secret tests such as zero, negative numbers and large values. A program that just prints the sample answer will fail them, so solve the general problem.

Input and output

Read from the keyboard with scanf in C or input() in Python. Print exactly what the problem asks, with no extra words like "Enter a number:".

Test yourself first

Run your program in VS Code with the sample input. Then try your own edge cases: 0, a negative number, and the largest value from the constraints.
